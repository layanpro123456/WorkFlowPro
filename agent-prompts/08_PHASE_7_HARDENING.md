# Prompt – Phase 7: Administration and Security Hardening

Implement admin user management, role management and audit log search. Then review:
- Authentication and authorization on every endpoint
- Resource-level authorization
- Internal ticket note privacy
- Refresh token rotation/revocation
- Rate limiting, CORS and security headers
- Safe production exception handling
- Structured logs without secrets
- Input limits, pagination bounds and report range bounds
- EF constraints, indexes and concurrency
- Dependency vulnerability status

Create a security test checklist and run all backend/frontend tests. Do not declare security complete based on a checklist alone; report limitations and evidence.
